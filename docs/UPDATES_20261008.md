## Source and version integrity

`docs/SOURCE_PROVENANCE.csv` maps public files to workspace-relative source paths and original SHA-256 values. Scientific source and recorded exports are preserved, except explicitly recorded publication adaptations. These include author-path substitution, removal of local plot-library fallbacks, exact guards for path-adapted plot JSON, plot formatting/typing cleanup and an explicit workspace-root parameter for the S22 scope guard. Scientific arithmetic and numeric inputs are preserved. Historical S22 code locks identify the original run; a fresh adapted run requires new coherent engineering locks. Figure scripts were originally written for standalone use; their publication-specific Ruff convention is recorded in the figure directory. The base threshold optimizer includes the September correction: cost ties require exact cost equality, then maximum integer TP, minimum integer alerts and highest threshold. It no longer admits a more expensive candidate through approximate equality. Historical August results remain historical; the updated implementation is not asserted to recreate them silently.

`PUBLIC_RELEASE_MANIFEST.csv` and `checksums.sha256` describe the current public snapshot. Package manifests cover the included subset, not the excluded author caches, model states or large replicate ledgers. `${WORKSPACE}` and `${AUTHOR_PROFILE}` are provenance placeholders, not automatically expanded runtime paths. Replace only input/output/provenance paths in a fresh reconstruction; preserve scientific fields, failed attempts and freeze boundaries. Original lock and code digests must not be represented as hashes of altered files.

The selected scope is the completed manuscript research chain. Separate exploratory history-acquisition proposals and unrelated local engineering pilots are not relabelled as manuscript evidence. No manuscript Word/PDF, source dataset or transaction-level scientific artifact is part of this update.
