# Dataset provenance and access

This repository does not redistribute either dataset.

## PaySim

PaySim is a synthetic mobile-money transaction simulator introduced in:

Edgar Alonso Lopez-Rojas, Ahmad Elmir, and Stefan Axelsson. “PaySim: A Financial Mobile Money Simulator for Fraud Detection.” Proceedings of the 28th European Modeling and Simulation Symposium, 2016, pp. 249-255.

Authoritative paper: https://www.msc-les.org/proceedings/emss/2016/EMSS2016_249.pdf

Users must obtain the data from an authorized source and place it locally as documented in the repository README.

## IEEE-CIS Fraud Detection

The IEEE-CIS Fraud Detection data were released through the official Kaggle competition by the IEEE Computational Intelligence Society with data provided by Vesta Corporation.

Official access page: https://www.kaggle.com/competitions/ieee-fraud-detection

The data are not included in this repository. Users must obtain them through the official platform under the applicable access conditions. This repository does not characterize IEEE-CIS as a dataset introduced by a peer-reviewed dataset paper.
