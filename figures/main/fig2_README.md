# Adopted Figure 2

`fig2.png` is the exact PNG embedded in the 2026-10-22 final manuscript. `fig2.svg` is the editable source export from `fig2_source_20261020/draw_figure.py`.

Run `python figures/main/fig2.py` in a writable copy to regenerate the SVG. The wrapper invokes the unchanged adopted drawing source and copies its SVG to this directory. It does not export a PNG or certify cross-platform pixel identity. The source uses installed macOS Arial font paths; other systems must adapt those paths. SVG text is editable and font binaries are not embedded.

The matrices, icons, score strips and split bars are schematic, not experimental observations. The authoritative final caption is `fig2_caption_submission.txt`.

The previous framework, PDF, preview and validation record are retained in Git history at `45ff895b86709b882678044d683491cf6aef4942`. They are not the current adopted artwork. Full-document layout receipts remain with the local submission preparation.
