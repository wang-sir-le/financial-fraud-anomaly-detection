# banksim

BankSim frozen validation, original code, artificial lifecycle tests and complete compact result tables.

This is the compact public snapshot of completed local evidence. Scientific numeric fields are preserved; author-local paths are explicit provenance placeholders. Original lock digests identify original files rather than the adapted public copy. See [the stage index](../../docs/UPDATES_20261008.md), [reconstruction limits](../../docs/REPRODUCIBILITY.md), and [source provenance](../../docs/SOURCE_PROVENANCE.csv).

The historical full-bundle guide, where supplied, also refers to excluded wheels, large replicate ledgers or source caches. Its interval-replay commands require those inputs and are not claimed to run from compact summary tables alone. Publication does not establish independent external raw-to-model reconstruction.

Run artificial tests from `code/` with `python -m pytest`. Install the recorded scientific dependencies, including XGBoost, first. The fixture forbids real model fits. For new input reconstruction, inspect the historical guide; its full binary Bootstrap files are excluded here.
