# Raw data location

Raw datasets are not redistributed by this repository and are ignored by Git.

- Place PaySim at `data/raw/PS_20174392719_1491204439457_log.csv`.
- Place IEEE-CIS files at `data/raw/ieee_cis/train_transaction.csv` and `data/raw/ieee_cis/train_identity.csv`.

See `docs/DATA_ACCESS.md` for authoritative sources and access guidance.
